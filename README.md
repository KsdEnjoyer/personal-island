# Personal Island

**Задачи, напоминания, музыка и заметки — в небольшом островке на рабочем столе.**

Windows 10/11 · Открытый исходный код · Ранняя версия

[Начать пользоваться](#установка-через-своего-агента) · [Возможности](#что-внутри) · [Что нового](#обновление-24-ноября-2026) · [Инструкции](#документация) · [MIT](LICENSE)

</div>

---

Personal Island — компактный виджет для Windows. Нажми **Ё / \`**, чтобы
посмотреть время и дела, управлять музыкой или открыть нужный раздел.
Нажми ещё раз — островок скроется. Напоминания появляются прямо в нём.

**Установка и настройка задуманы через твоего личного AI-агента.** Дай ему
ссылку на этот репозиторий: он проверит зависимости, соберёт приложение
и подключит инструменты для работы с твоим расписанием. После настройки
можно просить агента добавить задачу или перенести напоминание обычными словами.

## Что внутри

| Раздел | Что можно делать |
| --- | --- |
| **Задачи и календарь** | Записывать дела, назначать сроки, смотреть месяц. Двойной клик по неделе открывает подробный планировщик. |
| **Напоминания** | Получать уведомления с колокольчиком в островке. При запуске и через выбранный интервал видеть обзор пропущенных и ближайших незавершённых дел. По умолчанию — в :00 и :30. |
| **Музыка** | Смотреть обложку, ставить трек на паузу, переключать музыку и менять громкость плеера. Запускать Яндекс Музыку с главной. Нижняя волна реагирует на звук. |
| **Заметки, идеи, покупки** | Хранить записи в отдельных разделах, оформлять текст и составлять списки. |
| **Буфер обмена** | Возвращаться к скопированному тексту, изображениям и ссылкам на локальные файлы. Искать, закреплять и вставлять записи в окно ввода. |
| **Погода** | Смотреть текущую погоду и прогноз для Санкт-Петербурга. |
| **Таймер** | Запускать круглый таймер фокуса в разделе «Сегодня», задавать свою длительность и добавлять время на ходу. |

### Несколько полезных деталей

- **Островок по запросу.** Клавиша **Ё / \`** показывает и скрывает его.
  В настройках можно выбрать другую клавишу или сочетание, а также запретить
  печатать Ё / \` при вызове. По умолчанию символ печатается; два последовательных
  нажатия за 1,5 секунды убирают первый напечатанный символ.
- **Музыка под рукой.** В компактном островке есть обложка с паузой по нажатию
  и стрелки переключения. На паузе трек остаётся виден, пока плеер открыт.
  Колёсико над обложкой или значком громкости меняет громкость плеера.
  Перемотка доступна в разделе «Музыка». Поддержка этих действий зависит
  от плеера и его интеграции с Windows.
- **История буфера — по желанию.** В новой установке запись выключена.
  После включения видны последние **9 копирований** и отдельно закреплённые записи.

## Обновление 24 ноября 2026

### Музыка и громкость

- Трек остаётся в островке на паузе. Нажатие на обложку возобновляет музыку;
  закрытие плеера убирает её из островка.
- В разделе «Музыка» появилась перемотка трека. Положение сохраняется и при перемотке на паузе.
- Громкость плеера можно менять колёсиком над обложкой или значком динамика.
  Над обложкой тонкая вертикальная шкала появляется только после прокрутки,
  над динамиком — при наведении. Шкала выходит за границы островка, сохраняя его размер,
  и закрывается после ухода курсора. Системная громкость при этом не меняется.
- Эквалайзер снова работает независимо от эффекта «жидкого» края:
  на звук реагирует нижняя волна. Его можно отключить отдельно в настройках.

### Настройки и таймер

- Можно переназначить вызов островка и включить режим, в котором Ё / \` не печатается
  в активном окне. В текстовых редакторах самого островка буква остаётся доступна.
- Периодический показ настраивается: можно выбрать интервал, ввести свой
  или отключить автопоказ. Напоминания на конкретное время продолжат приходить.
  По умолчанию островок появляется каждые полчаса — в :00 и :30.
- Круглый таймер в «Сегодня» получил настройку длительности от 1 до 240 минут.
  Время можно добавить во время работы. Из заметок, идей и покупок таймер убран,
  чтобы оставить больше места записям.

### Работа с текстом

- При выделении текста в заметках, идеях, покупках, описаниях задач и событий,
  а также быстрых заметках календаря появляется панель оформления:
  **жирный**, *курсив*, подчёркивание, ~~зачёркивание~~, выделение цветом и очистка стиля.
- Оформление сохраняется между запусками. Редакторы загружаются по мере открытия разделов.

### Безопасность

- Обновлены зависимости `cookie` и `url` с исправлениями уязвимостей.

## Установка через своего агента

Понадобится личный AI-агент, который умеет работать с файлами и запускать
команды на твоём компьютере. Один только чат без такого доступа не сможет
установить приложение.

**1. Открой своего агента.**

**2. Скопируй ему этот запрос:**

```text
Установи и настрой Personal Island на моём компьютере:
https://github.com/KsdEnjoyer/personal-island

Прочитай AGENTS.md, README.md и docs/AGENT_SETUP_RU.md.
Проверь зависимости, собери приложение и сделай удобный способ запуска.
Подключи локальный MCP к моему AI-клиенту для работы с задачами.
Используй мой часовой пояс. Тесты записи проводи на отдельной временной базе.
Для удалённого подключения используй только мой сервер и мои ключи.
Не выводи секреты в чат. Проверь подключение и объясни, как всем пользоваться.
```

**3. Агент выполнит настройку и проверит результат.** Если ему не хватает
доступа или информации о твоём AI-клиенте, он уточнит это в процессе.
Зависимости устанавливаются на твой компьютер; приложение само их не скачивает.

Полный порядок действий: **[инструкция для личного агента](docs/AGENT_SETUP_RU.md)**.

### После подключения

MCP — это подключение, через которое агент получает инструменты для работы
с задачами островка. Можно обращаться к нему так:

> «Что у меня запланировано на сегодня?»
>
> «Добавь на завтра в 16:00: забрать заказ. Напомни за полчаса».
>
> «Перенеси задачу “Забрать заказ” на пятницу, 18:00».

Агент работает с задачами и напоминаниями. Доступа к заметкам, буферу обмена,
файлам и аудио через эти MCP-инструменты нет. Подключай доверенный клиент
и включай в нём подтверждение действий, которые меняют данные.

## Нужен ли сервер?

| Как хочешь пользоваться | Что понадобится |
| --- | --- |
| Островок на рабочем столе | Только твой компьютер. |
| Островок + локальный AI-агент | Твой компьютер и AI-клиент с поддержкой локального MCP. VPS не нужен. |
| Подключение из веб-ChatGPT | Дополнительно твой собственный VPS, домен и HTTPS/OAuth-шлюз. [Инструкция](docs/CHATGPT_MCP_RU.md). |

**Сервер автора не используется.** Общего серверного аккаунта или готового
облачного хранилища у проекта нет. Для удалённого доступа каждый пользователь
настраивает собственную инфраструктуру со своими ключами.

Локальный MCP не требует OpenAI API-ключа. Выбранный AI-клиент, VPS и домен
могут иметь свою стоимость.

## Где хранятся данные

Задачи, заметки и включённая история буфера хранятся на твоём компьютере,
по умолчанию — в `%LOCALAPPDATA%\PersonalIsland`. Приложение не шифрует эти
файлы и не отправляет их в общее хранилище проекта. Телеметрии нет.

При работе через агента запрошенные данные задач получает выбранный AI-клиент
и используемая им модель; при удалённом подключении они также проходят через
твой VPS. Погода загружается из Open-Meteo, музыка использует выбранный плеер
или музыкальный сервис. Волна анализирует выходной звук Windows без записи
аудио и без доступа к микрофону.

<details>
<summary><strong>Подробнее о локальных файлах и истории буфера</strong></summary>

| Файл | Содержимое |
| --- | --- |
| `tasks.sqlite3` | Задачи, даты, статусы и данные для защиты от повторного создания задач через MCP. |
| `notes.sqlite3` | Заметки, идеи и покупки. |
| `clipboard.sqlite3` | История буфера и пути локальных файлов, если запись включена. |
| `weather.json` | Кеш погоды. |

Переменная `PERSONAL_ISLAND_DB` меняет путь базы задач и расположение соседних
файлов. Приложение и MCP должны использовать один путь. Делай согласованную
резервную копию SQLite при закрытых процессах или через SQLite backup API.

Интерфейс показывает 9 последних копирований, но в хранилище могут оставаться
до 100 незакреплённых записей с ограничением размера и закреплённые записи.
Пауза записи не очищает историю. Приложение учитывает метки исключения,
которые выставляют некоторые менеджеры паролей, но не распознаёт любой секрет.

</details>

## Текущее состояние

Проект развивается и пока требует сборки из исходников. Подписанных публичных
установщиков и автоматического обновления пока нет. Desktop рассчитан на
**Windows 10/11**; отдельный локальный MCP также собирается на Linux/macOS.
Город в погоде пока фиксирован — Санкт-Петербург.

<details>
<summary><strong>Ручная сборка и запуск</strong></summary>

Нужны Git, Node.js 24 LTS с npm, Rust stable с MSVC target,
Visual Studio C++ Build Tools с Windows SDK и WebView2 Runtime.
[Системные требования Tauri](https://v2.tauri.app/start/prerequisites/).

В PowerShell из корня клонированного репозитория:

```powershell
npm.cmd --prefix apps/desktop ci
npm.cmd --prefix apps/desktop run tauri -- dev
```

Для сборки приложения и установщика:

```powershell
npm.cmd --prefix apps/desktop run tauri -- build
```

Установщик появится в `target/release/bundle/nsis/`. После сборки ярлык можно
создать скриптом `scripts/create-desktop-shortcut.ps1`.

Для сборки локального MCP:

```powershell
cargo build --locked --release -p task-mcp
```

Далее следуй [инструкции подключения MCP](docs/LOCAL_MCP_RU.md).

</details>

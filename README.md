# Personal Island

Небольшой виджет для Windows 10/11: задачи, календарь, напоминания, заметки,
музыка, погода и история буфера. **Основной способ установки и настройки —
через личного AI-агента пользователя:** он собирает приложение на твоём
компьютере, подключает локальный MCP и помогает управлять расписанием.
Данные хранятся на компьютере. MCP позволяет совместимому AI-клиенту читать
и изменять задачи.
Проект на ранней стадии; лицензия кода — [MIT](LICENSE).

## Начни со своего агента

Открой этот репозиторий в своём агенте с доступом к локальным файлам и терминалу
и отправь ему:

> Установи и настрой Personal Island на моём компьютере. Прочитай AGENTS.md,
> README.md и docs/AGENT_SETUP_RU.md, проверь зависимости, собери приложение
> и подключи локальный MCP к моему AI-клиенту. Используй мои локальные данные
> и часовой пояс. Не создавай тестовые задачи в личном расписании. Если понадобится
> удалённое подключение, используй только мой сервер и мои ключи; секреты в чат
> не выводи. Проверь результат и объясни, как запускать островок.

**[Пошаговая инструкция для личного агента](docs/AGENT_SETUP_RU.md).**
Это инструкция для агента, которому ты даёшь доступ к своему компьютеру;
приложение само не устанавливает зависимости и не настраивает AI-клиент.
Ручная установка также описана ниже.

**Сервера автора в этой схеме нет.** Приложение и локальный MCP работают
на компьютере пользователя без VPS. Для подключения веб-ChatGPT по HTTPS
пользователь при желании поднимает шлюз на **своём** VPS со **своим** доменом,
OAuth-конфигурацией и ключами. Общего backend, готового серверного аккаунта
или доступа к инфраструктуре автора проект не предоставляет. Внешние
погодный и музыкальный сервисы, а также выбранный AI-клиент описаны
в разделе о приватности.

## Возможности

- **Ё / `** показывает и скрывает островок. Один символ проходит в активное
  окно; два последовательных нажатия за 1,5 секунды убирают первый символ.
- Календарь месяца; двойной клик по неделе открывает планировщик.
- Колокольчик для новых напоминаний. При запуске и в :00/:30 — обзор пропущенных
  и ближайших незавершённых дел.
- Заметки, идеи, покупки, таймер фокуса.
- Управление медиасессиями Windows, запуск Яндекс Музыки, обложки и волна,
  реагирующая на выходной звук. Поддержка зависит от плеера.
- Погода Санкт-Петербурга из Open-Meteo; город пока фиксирован.
- Буфер: текст, изображения, ссылки на локальные файлы, поиск и закрепление.
  **В новой установке запись выключена до явного включения.**

## Запуск из исходников

Нужны Windows 10/11, Git, Node.js 24 LTS с npm, Rust stable с MSVC target,
Visual Studio C++ Build Tools с Windows SDK и WebView2 Runtime.
[Требования Tauri](https://v2.tauri.app/start/prerequisites/).

В PowerShell из корня клонированного репозитория:

```powershell
npm.cmd --prefix apps/desktop ci
npm.cmd --prefix apps/desktop run tauri -- dev
```

Сборка приложения и установщика:

```powershell
npm.cmd --prefix apps/desktop run tauri -- build
```

Установщик появится в `target/release/bundle/nsis/`. Для локального ярлыка
после сборки есть `scripts/create-desktop-shortcut.ps1`. Подписанных публичных
релизов и автоматического обновления пока нет.

## Подключить свой MCP

Для локального клиента сервер работает через **stdio**: без VPS, открытых
портов и API-ключа OpenAI.

```powershell
cargo build --locked --release -p task-mcp
```

Укажи абсолютный путь к `target/release/task-mcp.exe` как команду MCP в клиенте.
Процесс запускает сам клиент; в обычном терминале он ждёт JSON-RPC во stdin.

- **[Подробная инструкция: локальный MCP](docs/LOCAL_MCP_RU.md)** — Codex,
  другие клиенты, своя база, часовой пояс, локальный HTTP и диагностика.
- [Пример конфигурации stdio](examples/mcp-stdio.example.json).
- [Веб-ChatGPT и свой VPS](docs/CHATGPT_MCP_RU.md) — необязательный HTTPS/OAuth.
  Проект не предоставляет общий сервер; адреса в примерах нужно заменить.

Инструменты: `get_current_time`, `list_tasks`, `list_schedule`, `get_task`,
`create_task`, `create_tasks`, `update_task`, `reschedule_task`,
`complete_task`, `reopen_task`, `delete_task`. Подключённый клиент может менять
задачи: используй доверенный клиент и подтверждение изменяющих действий в нём.
Буфер, файлы, заметки, аудио и медиасессии эти MCP-инструменты не раскрывают.

## Данные и приватность

По умолчанию файлы лежат в `%LOCALAPPDATA%\PersonalIsland`:

| Файл | Данные |
| --- | --- |
| `tasks.sqlite3` | Задачи, даты, статусы, квитанции повторных MCP-запросов |
| `notes.sqlite3` | Заметки, идеи и покупки |
| `clipboard.sqlite3` | Включённая пользователем история буфера и пути файлов |
| `weather.json` | Кеш погоды |

Это обычные локальные файлы, **без шифрования приложением**. Переменная
`PERSONAL_ISLAND_DB` меняет путь базы задач и расположение соседних файлов;
приложение и MCP должны использовать один путь. Делай согласованную резервную
копию SQLite при закрытых процессах или через SQLite backup API.

Видны последние 9 копирований и отдельно закреплённое. В хранилище могут
оставаться до 100 незакреплённых записей с ограничением размера и закреплённые.
Пауза записи не удаляет историю. Некоторые менеджеры паролей выставляют opt-out
метки буфера: приложение их учитывает, но не может распознать любой секрет.

Анализатор музыки читает общий выходной звук Windows, а не микрофон; сэмплы
не записываются. Погода обращается к Open-Meteo; музыкальный сервис открывается
по соответствующему действию. Телеметрия не добавлена. MCP передаёт запрошенные
данные задач выбранному клиенту/модели; удалённая схема также пропускает их
через твой VPS. [Модель доверия](SECURITY.md).

## Разработка

| Каталог | Назначение |
| --- | --- |
| `crates/task-core` | Общая логика задач и SQLite |
| `crates/task-mcp` | stdio и необязательный private HTTP |
| `apps/desktop` | Svelte 5 + Tauri 2, Windows host |
| `services/mcp-gateway` | Необязательный single-owner OAuth-шлюз |
| `scripts` | Сборка, проверки и отдельно запускаемые интеграционные тесты |

```powershell
.\scripts\check.ps1
```

Начни с [CONTRIBUTING.md](CONTRIBUTING.md). Проверки используют временные базы.
Тесты живого VPS и прерывания соединения не входят в обычный CI.

# Personal Island

**Задачи, напоминания, музыка и заметки — в небольшом островке на рабочем столе.**

---

Personal Island — компактный виджет для Windows и Linux. Открой островок, чтобы
посмотреть время и дела, управлять музыкой или перейти в нужный раздел.
Напоминания появляются прямо в нём.

**Установка и настройка задуманы через твоего личного AI-агента.** Дай ему
ссылку на этот репозиторий: он проверит зависимости, соберёт приложение
и подключит инструменты для работы с твоим расписанием. После настройки
можно просить агента добавить задачу или перенести напоминание обычными словами.

## Что внутри

| Раздел | Что можно делать |
| --- | --- |
| **Задачи и календарь** | Записывать дела, назначать сроки, смотреть месяц. Двойной клик по неделе открывает подробный планировщик. |
| **Напоминания** | Получать уведомления с колокольчиком в островке. При запуске и через выбранный интервал видеть обзор пропущенных и ближайших незавершённых дел. По умолчанию — в :00 и :30. |
| **Музыка** | Смотреть обложку, ставить трек на паузу, переключать музыку и менять громкость плеера. Запускать Яндекс Музыку с главной. Нижняя волна реагирует на звук. |
| **Заметки, идеи, покупки** | Хранить записи в отдельных разделах, оформлять текст и составлять списки. |
| **Буфер обмена** | Возвращаться к скопированному тексту, изображениям и ссылкам на локальные файлы. Искать, закреплять и вставлять записи в окно ввода. |
| **Погода** | Смотреть текущую погоду и прогноз для Санкт-Петербурга. |
| **Таймер** | Запускать круглый таймер фокуса в разделе «Сегодня», задавать свою длительность и добавлять время на ходу. По завершении островок показывает сообщение и подаёт сигнал, даже если был скрыт. |

### Несколько полезных деталей

- **Островок по запросу.** На Windows клавиша **Ё / \`** показывает и скрывает его.
  В настройках можно выбрать другую клавишу или сочетание, а также запретить
  печатать Ё / \` при вызове. По умолчанию символ печатается; два последовательных
  нажатия за 1,5 секунды убирают первый напечатанный символ. На Linux островок
  на X11 по умолчанию вызывается через **Ctrl+Alt+I**. На Wayland приложение
  предлагает то же сочетание через системный портал.
- **Музыка под рукой.** В компактном островке есть обложка с паузой по нажатию
  и стрелки переключения. На паузе трек остаётся виден, пока плеер открыт.
  Колёсико над обложкой или значком громкости меняет громкость плеера.
  Перемотка доступна в разделе «Музыка». Поддержка этих действий зависит
  от плеера и его поддержки системных медиакоманд (MPRIS на Linux).
- **История буфера — по желанию.** В новой установке запись выключена.
  После включения видны последние **9 копирований** и отдельно закреплённые записи.

## Обновление 24 ноября 2026

### Музыка и громкость

- Трек остаётся в островке на паузе. Нажатие на обложку возобновляет музыку;
  закрытие плеера убирает её из островка.
- В разделе «Музыка» появилась перемотка трека. Положение сохраняется и при перемотке на паузе.
- Громкость плеера можно менять колёсиком над обложкой или значком динамика.
  Над обложкой тонкая вертикальная шкала появляется только после прокрутки,
  над динамиком — при наведении. Шкала выходит за границы островка, сохраняя его размер,
  и закрывается после ухода курсора. Системная громкость при этом не меняется.
- Эквалайзер снова работает независимо от эффекта «жидкого» края:
  на звук реагирует нижняя волна. Его можно отключить отдельно в настройках.

### Настройки и таймер

- Можно переназначить вызов островка. На Windows можно отключить ввод Ё / \`
  при вызове. В редакторах самого островка буква остаётся доступна.
- Периодический показ настраивается: можно выбрать интервал, ввести свой
  или отключить автопоказ. Напоминания на конкретное время продолжат приходить.
  По умолчанию островок появляется каждые полчаса — в :00 и :30.
- Круглый таймер в «Сегодня» получил настройку длительности от 1 до 240 минут.
  Время можно добавить во время работы. Из заметок, идей и покупок таймер убран,
  чтобы оставить больше места записям.

### Работа с текстом

- При выделении текста в заметках, идеях, покупках, описаниях задач и событий,
  а также быстрых заметках календаря появляется панель оформления:
  **жирный**, *курсив*, подчёркивание, ~~зачёркивание~~, выделение цветом и очистка стиля.
- Оформление сохраняется между запусками. Редакторы загружаются по мере открытия разделов.

### Безопасность

- Обновлены зависимости `cookie` и `url` с исправлениями уязвимостей.

## Установка через своего агента

Понадобится личный AI-агент, который умеет работать с файлами и запускать
команды на твоём компьютере. Один только чат без такого доступа не сможет
установить приложение.

**1. Открой своего агента.**

**2. Скопируй ему этот запрос:**

```text
Установи и настрой Personal Island на моём компьютере:
https://github.com/KsdEnjoyer/personal-island

Прочитай AGENTS.md, README.md и docs/AGENT_SETUP_RU.md.
Проверь зависимости, собери приложение и сделай удобный способ запуска.
Подключи локальный MCP к моему AI-клиенту для работы с задачами.
Используй мой часовой пояс. Тесты записи проводи на отдельной временной базе.
Для удалённого подключения используй только мой сервер и мои ключи.
Не выводи секреты в чат. Проверь подключение и объясни, как всем пользоваться.
```

**3. Агент выполнит настройку и проверит результат.** Если ему не хватает
доступа или информации о твоём AI-клиенте, он уточнит это в процессе.
Зависимости устанавливаются на твой компьютер; приложение само их не скачивает.

Полный порядок действий: **[инструкция для личного агента](docs/AGENT_SETUP_RU.md)**.

### После подключения

MCP — это подключение, через которое агент получает инструменты для работы
с задачами островка. Можно обращаться к нему так:

> «Что у меня запланировано на сегодня?»
>
> «Добавь на завтра в 16:00: забрать заказ. Напомни за полчаса».
>
> «Перенеси задачу “Забрать заказ” на пятницу, 18:00».

Агент работает с задачами и напоминаниями. Доступа к заметкам, буферу обмена,
файлам и аудио через эти MCP-инструменты нет. Подключай доверенный клиент
и включай в нём подтверждение действий, которые меняют данные.

## Нужен ли сервер?

| Как хочешь пользоваться | Что понадобится |
| --- | --- |
| Островок на рабочем столе | Только твой компьютер. |
| Островок + локальный AI-агент | Твой компьютер и AI-клиент с поддержкой локального MCP. VPS не нужен. |
| Подключение из веб-ChatGPT | Дополнительно твой собственный VPS, домен и HTTPS/OAuth-шлюз. [Инструкция](docs/CHATGPT_MCP_RU.md). |

**Сервер автора не используется.** Общего серверного аккаунта или готового
облачного хранилища у проекта нет. Для удалённого доступа каждый пользователь
настраивает собственную инфраструктуру со своими ключами.

Локальный MCP не требует OpenAI API-ключа. Выбранный AI-клиент, VPS и домен
могут иметь свою стоимость.

## Где хранятся данные

Задачи, заметки и включённая история буфера хранятся на твоём компьютере,
по умолчанию — в `%LOCALAPPDATA%\PersonalIsland` на Windows и
`$XDG_DATA_HOME/PersonalIsland` на Linux (обычно `~/.local/share/PersonalIsland`).
Приложение не шифрует эти
файлы и не отправляет их в общее хранилище проекта. Телеметрии нет.

При работе через агента запрошенные данные задач получает выбранный AI-клиент
и используемая им модель; при удалённом подключении они также проходят через
твой VPS. Погода загружается из Open-Meteo, музыка использует выбранный плеер
или музыкальный сервис. Волна анализирует системный звук без записи
аудио и без доступа к микрофону.

<details>
<summary><strong>Подробнее о локальных файлах и истории буфера</strong></summary>

| Файл | Содержимое |
| --- | --- |
| `tasks.sqlite3` | Задачи, даты, статусы и данные для защиты от повторного создания задач через MCP. |
| `notes.sqlite3` | Заметки, идеи и покупки. |
| `clipboard.sqlite3` | История буфера и пути локальных файлов, если запись включена. |
| `widget-settings.json` | Сочетание вызова и интервал автопоказа. |
| `weather.json` | Кеш погоды. |

Переменная `PERSONAL_ISLAND_DB` меняет путь базы задач и расположение соседних
файлов. Приложение и MCP должны использовать один путь. Делай согласованную
резервную копию SQLite при закрытых процессах или через SQLite backup API.

Интерфейс показывает 9 последних копирований, но в хранилище могут оставаться
до 100 незакреплённых записей с ограничением размера и закреплённые записи.
Пауза записи не очищает историю. На Windows приложение учитывает метки
исключения некоторых менеджеров паролей. На Linux такие метки не стандартизированы.

</details>

## Запуск на Linux

Открой терминал в корне клонированного или распакованного репозитория и запусти
одну команду от своего пользователя.

**Arch Linux и Manjaro**

```sh
bash scripts/install-linux-pacman.sh
```

**Debian 12+ и Ubuntu 22.04+**

```sh
bash scripts/install-linux-apt.sh
```

Скрипт установит системные зависимости через `sudo`, подготовит Node.js и Rust,
соберёт приложение и добавит **Personal Island** в меню приложений. Вариант для
Pacman выполняет обычное обновление системы через `pacman -Syu`.
Приложение и значок устанавливаются в `$XDG_DATA_HOME/personal-island`
(обычно `~/.local/share/personal-island`). Для обновления запусти тот же скрипт
из актуальной копии проекта, затем перезапусти приложение.

<details>
<summary><strong>Готовые пакеты и AppImage</strong></summary>

### Готовые пакеты

После успешной сборки скачай артефакт `personal-island-linux-x86_64` из задачи
**linux-packages** в GitHub Actions. Пакеты собираются на Ubuntu 22.04
с glibc 2.35. [Требования Tauri к переносимым сборкам](https://v2.tauri.app/distribute/appimage/#limitations).

| Система | Формат | Установка или запуск |
| --- | --- | --- |
| Ubuntu 22.04+ и Debian 12+ | `.deb` | `sudo apt install "./Personal Island_0.1.0_amd64.deb"` |
| Fedora с WebKitGTK 4.1 | `.rpm` | `sudo dnf install ./пакет.rpm` |
| Arch, Manjaro и другие дистрибутивы с glibc 2.35+ | AppImage | См. команды ниже. |

Выполняй команды в папке со скачанным пакетом и подставь его имя, если оно
отличается. APT по умолчанию установит зависимости `.deb` и рекомендуемые
утилиты. Для готовых пакетов Node.js и Rust не нужны.

На Arch Linux и Manjaro первая команда установит FUSE и утилиты для музыки,
звука таймера и буфера обмена. Две следующие запустят AppImage.

```sh
sudo pacman -Syu --needed fuse2 playerctl libpulse glib2 xdg-utils wl-clipboard xclip
chmod +x "./Personal Island_0.1.0_amd64.AppImage"
"./Personal Island_0.1.0_amd64.AppImage"
```

Если запускаешь AppImage с `--appimage-extract-and-run`, пакет `fuse2` можно
пропустить. Для архитектур кроме x86_64 собери пакет из исходников на целевой
системе.

Чтобы добавить исполняемый AppImage в меню приложений, из корня репозитория
выполни:

```sh
./scripts/create-desktop-shortcut.sh "/путь/к/Personal Island_0.1.0_amd64.AppImage"
```

Если для запуска нужен `--appimage-extract-and-run`, передай его после пути
к AppImage. Если переместишь файл, создай ярлык заново.

### Запуск из исходников

Нужны Git, Node.js 22.12+ с npm, Rust stable и системные библиотеки Tauri для
Linux, в том числе GTK 3 и WebKitGTK 4.1. Команды также устанавливают утилиты
для музыки, звука таймера и буфера обмена. Для других дистрибутивов смотри
[официальные требования Tauri](https://v2.tauri.app/start/prerequisites/).

#### Arch Linux и Manjaro

```sh
sudo pacman -Syu --needed \
  git base-devel pkgconf curl ca-certificates file nodejs npm rustup \
  gtk3 webkit2gtk-4.1 openssl librsvg libayatana-appindicator \
  playerctl libpulse glib2 xdg-utils wl-clipboard xclip
rustup default stable
```

Если Rust stable уже настроен, убери `rustup` из списка пакетов и пропусти
`rustup default stable`.

#### Debian 12+ и Ubuntu 22.04+

```sh
sudo apt update
sudo apt install -y \
  git build-essential pkg-config curl ca-certificates file \
  libgtk-3-dev libwebkit2gtk-4.1-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev libxdo-dev \
  playerctl pulseaudio-utils libglib2.0-bin xdg-utils wl-clipboard xclip
```

Если на Ubuntu APT не находит `playerctl` или `libwebkit2gtk-4.1-dev`, выполни
этот блок для включения `universe` и повтори установку пакетов.

```sh
sudo apt install -y software-properties-common
sudo add-apt-repository -y universe
sudo apt update
```

Этот блок установит Node.js 24 с npm. Выполни его, если `node --version` ниже
22.12 или Node.js ещё отсутствует. [Инструкция nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
export NVM_DIR="$HOME/.nvm"
curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash
. "$NVM_DIR/nvm.sh"
nvm install 24
```

Этот блок установит Rust stable, если ты ещё его не настроил.
[Инструкция Rustup](https://rust-lang.org/tools/install/)

```sh
curl --proto '=https' --tlsv1.2 -fsS https://sh.rustup.rs \
  | sh -s -- -y --profile minimal --default-toolchain stable
. "$HOME/.cargo/env"
```

### Дополнительные возможности

Задачи, заметки и таймер запускаются без инструментов мультимедиа и буфера
обмена. `.deb` и `.rpm` объявляют эти инструменты рекомендуемыми зависимостями.
Для AppImage их можно установить через менеджер пакетов дистрибутива.

| Возможность | Что используется |
| --- | --- |
| Управление плеером, данные о треке и перемотка | `playerctl` и плеер с поддержкой MPRIS |
| Открытие Яндекс Музыки или Spotify | `gio`, а для сайта Яндекс Музыки — `xdg-open` |
| Управление громкостью и звуковая волна | `pactl` и `parec` с PulseAudio или PipeWire через `pipewire-pulse` |
| Звук таймера | `pacat` с PulseAudio или `pipewire-pulse`, либо `pw-play` или `aplay` |
| Копирование файлов | `wl-clipboard` на Wayland, `xclip` на X11 |
| Буфер обмена для текста и изображений | X11 или Wayland data-control на поддерживающих его композиторах |

В Ubuntu и Debian `gio` входит в `libglib2.0-bin`, в Fedora и Arch — в
`glib2`. Утилиты `pacat`, `pactl` и `parec` входят в `pulseaudio-utils` в Ubuntu,
Debian и Fedora, а в Arch — в `libpulse`. Для запуска
воспроизведения одним нажатием установи [настольную Яндекс Музыку](https://music.yandex.ru/download/),
войди в аккаунт; плеер должен публиковать MPRIS-сессию.
В разделе **Музыка** доступны установленные или запущенные настольные
Яндекс Музыка и Spotify. Островок сохраняет привязку при выборе приложения
в переключателе. Пункт **Автоматически** сбрасывает привязку и возвращает
автоматический выбор источника.

На X11 сочетание по умолчанию — **Ctrl+Alt+I**, его можно изменить в настройках островка.
На Wayland портал Global Shortcuts назначает сочетание. Проверь назначенную
клавишу в настройках островка. Кнопка «Настроить в системе» открывает диалог
на поддерживаемых версиях портала. Если портал отсутствует, сочетание занято
или привязка отклонена, открой Personal Island через меню приложений или
повторно запусти AppImage. В настройках рабочего стола можно назначить
системное сочетание на эту команду запуска. Повторный запуск покажет открытый
островок. Для автоматической вставки портал отдельно запросит разрешение
на управление клавиатурой.
На X11 вставка возвращает фокус
предыдущему окну и отправляет `Ctrl+V` напрямую. Если разрешение отклонено,
портал недоступен или предыдущее окно закрыто, запись остаётся скопированной:
перейди в нужное окно и нажми `Ctrl+V`. На Wayland возвращение фокуса зависит
от оконного менеджера.
При наличии XWayland GTK использует его для выравнивания окна у верхнего
края рабочей области. В сеансе без XWayland положение окна определяет
композитор. Явное значение `GDK_BACKEND` сохраняется.
Для идентификации portable AppImage в новых версиях портала создаётся скрытый
файл `$XDG_DATA_HOME/applications/dev.personalisland.desktop.desktop`
(по умолчанию в `~/.local/share/applications/`).

</details>

### Необязательное расширение для GNOME 50

Запусти актуальную сборку приложения и установи расширение из репозитория:

```sh
./scripts/install-gnome-panel.sh
```

Компактный островок займёт ячейку даты в верхней панели. Клик по нему или
**Ctrl+Alt+I** раскрывает и сворачивает привычный интерфейс. Остальные виджеты
панели остаются на своих местах. Чтобы вернуть дату, отключи расширение
Personal Island. Если GNOME уже загружал предыдущую версию расширения, новый
код загрузится при следующем входе в сеанс.

На GNOME Wayland островок записывает буфер по событиям GNOME Shell.
До загрузки расширения используется событийный буфер XWayland, если он
доступен. История хранится локально, а пауза записи сохраняет прежние записи.

</details>

## Локальный MCP

Для сборки локального MCP на Windows и Linux:

```sh
cargo build --locked --release -p task-mcp
```

Исполняемый файл — `target/release/task-mcp.exe` на Windows и
`target/release/task-mcp` на Linux. Далее следуй [инструкции подключения MCP](docs/LOCAL_MCP_RU.md).
